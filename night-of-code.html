PRE-SUMMIT ENGINEERING LAB / MONDAY 18 JANUARY 2027

One night.
Build something verifiable.

A focused, team-based engineering challenge immediately before the four-day summit. Participants work on practical post-quantum migration and datacentre security problems, then present reproducible results to peers and reviewers.

PROPOSED EVENT · PARTICIPATION, VENUE, CHALLENGES AND PRIZES SUBJECT TO CONFIRMATION

WHY A NIGHT OF CODE?

Move from discussion to working artefacts.

The Night of Code is the practical on-ramp to the summit. It gives engineers, researchers and students a shared environment to inspect real migration problems, prototype tools and test assumptions before the policy, architecture and industry discussions begin.

Format: evening engineering sprint, team formation, mentor clinics, code review and short demonstrations. It is one pre-summit event, not a fifth summit day.

CHALLENGE 01

PQC migration engineering

Build or extend a cryptographic inventory, dependency scanner, migration-readiness report or hybrid-protocol test harness. Outputs should identify assumptions and standards versions.

CHALLENGE 02

Datacentre trust and assurance

Prototype a verification workflow for certificate/key lifecycle, service identity, secure configuration or post-quantum readiness across infrastructure components.

CHALLENGE 03

Performance and interoperability

Measure implementation trade-offs, message sizes, latency, memory or compatibility for selected post-quantum algorithms and hybrid deployments.

CHALLENGE 04

Agentic security engineering

Explore bounded agent-assisted inventory, testing or remediation workflows. Tool permissions, evidence capture and human approval must be explicit.
